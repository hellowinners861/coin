# 盤面デザイン追補・Sol向け制作指示書

作成日：2026-10-15 / 版：1.0 / 対象：coin

本書は盤面のデザインと後日の制作指示を記した文書。今回の作業範囲は文書追加のみで、プログラム、3Dモデル、ゲーム本体は制作しない。寸法・材質値はデザインの基準案であり、動作確認済みの製造図ではない。

## 1. この追補の優先順位

ユーザーの追加指定を反映した最新の盤面仕様として、GAME_DESIGN.mdの旧記述より本書を優先する。

1. 投入口は手前にあり、そこを支点に左右へ向きを振る。
2. メダルは手前から最奥までレールを流れ、奥で上段に落ちる。奥からいきなり出現する見せ方にはしない。
3. 奥に上段の可動台、手前に下段の固定台を置く。
4. 上段から下段へ落ちる場所は上段の前縁。盤面外へ落ちる場所は下段の手前だけ。
5. 左右・背面に落下口や没収経路を設けない。メダルもボールも同じ方針。
6. チープな模型感を避け、素材・構造・光の整合がある遊技機として仕上げる。
7. イベントの世界観、キャラクター、物語は引き続き未決定。

## 2. 採用するデザインの方向性

**深い緑の塗装を施した筐体に、サテン仕上げの金属盤面を収めた、落ち着いた実物感のある遊技機。**

最初に目に入るのは、広い金属の棚、そこに積もったメダル、薄い段差の光、手前から奥へ走るメダル。筐体はこれらを額縁のように支える。

上品さは装飾の多さで作らず、板厚、継ぎ目、曲げ加工、素材ごとの反射、接触部分の影で作る。古びたアンティークではなく、手入れの行き届いた機械の質感を目標にする。ゲームセンターらしい期待感は、メダルの集積、ボール、タワー、実際の落下に持たせる。

盤面そのもののデザインはこの一案にまとめる。正式タイトルやイベントテーマを示すロゴ、動物、競技場、宇宙・カジノなどの世界観は追加しない。

### 色と役割

色は照明を当てる前の参考色。金属色はベタ塗りではなく、反射と粗さを含めて判断する。

| 対象 | 基準色 | 仕上げと役割 |
| --- | --- | --- |
| 筐体外周 | #233F3B | 深い緑。微細な凹凸のある半艶塗装。大きな面の基調。 |
| 上段・下段の棚 | #A5AAA7 | やや温かい銀。細いヘアラインが見えるサテン金属。 |
| 奥の機構カバー | #303735 | チャコール。棚より暗く、最奥の落下を読み取れる背景。 |
| レールの支点・細い縁 | #A68B5D | 低彩度のシャンパンブラス。限定した部品だけ。 |
| メダル | #C1B58F | 淡いシャンパン色。棚と材質・明度を分ける。 |

固定筐体の見付面では、銀系約55%、深緑約30%、暗い機構約10%、ブラスと表示灯合計約5%を目安にする。メダルやボールの面積はこの配分から除く。盤面全面を金色にしない。

## 3. 画面に見える完成像

プレイヤー側から少し高い位置で見下ろす。最前面に低い操作縁、その中央に首振り投入口の支点がある。細いレールが盤面の上を奥へ伸び、先端だけが下向きに折れ、奥の棚へメダルを落とす。

奥の棚は、厚みのある押し台に載った明るい金属面。棚の前縁に細いハイライトが入り、その下の広い下段は、少し反射を抑えた金属面になる。下段の左右は閉じた壁で囲まれ、手前の長い一辺だけが回収口へ開く。

筐体の緑は外周に残し、コインが接する面は金属に揃える。奥は暗く、棚は明るく、回収口の内部は一段暗い。段差と奥行きを、発光する輪郭線に頼らず読める構成にする。

## 4. 配置と寸法の基準

方向を統一する。「手前」はプレイヤー側、「奥」は投下先。下段の手前落下縁を奥行き0、背面側を正とする。横の原点は盤面中央、下段床の高さを0とする。Dはメダル直径25mm。

| 部位・位置 | デザイン基準 | 補足 |
| --- | --- | --- |
| 有効盤面の内幅 | 14D＝350mm | 旧案の12Dを、このデザインでは置き換える。 |
| 有効盤面の奥行き | 18D＝450mm | 旧案の16Dを置き換える。 |
| 下段の主な見える範囲 | 手前0〜10.8D程度 | 広い連続面。最も長く観察する領域。 |
| 上段の前縁 | 奥行き10.8〜12Dを往復 | ストローク1.2D。 |
| 上段の面高さ | 1.2D＝30mm | 薄い板を浮かせず、押し台の箱形状で支える。 |
| 上段奥の着地帯 | 奥行き16〜17.4D付近 | 押し台の全行程で棚がこの範囲を覆う。 |
| 投入口の支点 | 奥行き-1D、横中央付近 | 下段の外側、プレイヤー側の操作縁に固定。 |
| レールの始端走行面 | 高さ約7D＝175mm | 手前が高く、奥へ緩く下がる。 |
| レールの末端走行面 | 高さ約4.2D＝105mm | 終端の下向きガイドで奥の棚へ案内。 |
| レールの長さ | ノズルを含め約18D | 盤面のほぼ全奥行きを走る細い部材。 |
| 左右の首振り | 約±17度から検討 | 旧案の±35度を置き換える。最奥の着地帯を外さないことを優先。 |
| 下段の回収口 | 内幅いっぱいの連続開口 | 左右端まで手前回収。見せかけの当たり幅を作らない。 |
| 外周の塗装フレーム | 片側0.45〜0.65D程度 | 太い縁で盤面を狭めない。 |

支点からの一定長の首振りでは、先端が円弧を描く。中心時の先端は最奥、左右へ振ると少し手前になる。その変化を着地帯の奥行きで受ける。左右端で先端だけ横へスライドするような不整合は作らない。

約18Dのレールを±17度振ると先端の左右変位は約5.3D。内幅の半分7Dに対して余裕を残す構成になる。ノズルの曲がり、側壁厚、メダルの跳ねを含めた正確な軌跡は後日の立体検討で決める。限界角を広げて側壁へ向ける調整はしない。

## 5. 手前から最奥へ送る投入口

### 5.1 メダルの通り道

手前の受入口で縦に立ったメダルを受け、細い溝付きレールを奥へ転がす。幅広い滑り台に平らなコインを載せる形ではなく、メダルの円周が走行面に接する形を採用する。

傾きは全体で9度前後を目安にする。転がる経路であることを見た目にも伝え、摩擦のある平板上を、浅い角度なのに不自然に滑っていく表現を避ける。投入時の押し出しが必要なら、手前の送り機構として形にする。

最奥の終端には短い下向きの曲面ガイドを付け、奥向きの運動を下方へ向ける。後壁へ高速でぶつけて跳ね返す方式にはしない。終端から棚までの最後の短い落下は見せる。

メダルが手前から奥へ移動する一連の経路を省略しない。残高が減った瞬間に奥へ生成する方式、空中を光の線で飛ぶ方式、レールに沿って動いた後に別のメダルへ置き換える表現は、このデザインの意図から外れる。

### 5.2 レールの造形

- 主材はサテン仕上げの銀色金属。幅は外形0.45〜0.65D程度を目安とし、盤面を横断する大きな板にしない。
- 溝の幅はメダル厚と横ぶれに必要な余裕から決める。支持面・左右の案内面・終端をひと続きに見せる。
- 走行中のメダルの上側が見える断面にし、長い不透明な筒に隠さない。
- 端部は曲げ加工や小さな面取りを表現する。玩具の厚いプラスチック棒のように丸めない。
- 中央支点は低い円柱と扇形の軸受カバー。ここだけ鈍いブラスを使う。
- レールは支点から片持ちで伸ばす。太い支柱を下段の中央に立てない。支点の厚みと付け根の補強で支持を説明する。
- 横に振ると支点・軸受・レール・終端が一体で向きを変える。意味のない歯車や配線は足さない。
- 長いレールの下に硬い黒い影を落とさず、細く柔らかい影で存在を伝える。

### 5.3 タワーとの干渉

レールは盤面より十分上を通す。標準120枚タワーの試作高さは、3枚×40層なら約72mmで、下段の高さ基準で約2.9Dになる。搬入域と倒れる範囲を含め、レール下面まで最低0.8D程度の余裕を目標にする。

タワーは中央奥寄りでも、レールの影と重なり続けないよう横へ少し寄せる。左右どちらを定位置にするかは、後日の固定カメラ構図で決める。大きいタワーを後から追加する場合は、先にレール・透明カバーの高さを再検討する。

## 6. 上段：動きが読める金属の棚

### 6.1 面・前縁・側面

上段は1枚のサテン金属板と、その下の箱状の押し台で構成する。天面は下段より少しだけ反射を強くし、前後運動で細いハイライトが移動するようにする。面を大きな鏡にしない。

前縁は基本的に一直線。ごく小さな面取りに光が乗り、落下する境界を読み取れる形にする。厚い手すりや高い装飾の返しを付けない。棚面に派手な柄、矢印、光る格子を入れない。

前面の押す部分は、上段天面から下段床近くまで降りる金属の面。床との隙間はコインの厚みより小さく、メダルが下へ潜り込まない設計にする。動作のための逃げと見た目の薄さは、機構部分として整える。

### 6.2 奥と側面の納まり

可動棚の後端は暗い固定背板の下へ差し込まれ、全往復行程で着地帯を覆う。必要な後端の移動空間は筐体背面内に確保する。前進したときに投下口の下が空洞になる設計にしない。

左右の機構隙間は重なりを持つ側面カバーで閉じる。そこへメダルが抜けたり、横から下段へ落ちたりする経路を設けない。上段の出口は前縁のみ。

固定部と可動部の境界は、暗い小さな継ぎ目として見せる。継ぎ目が「落とすと損をする穴」に見えない幅と納まりにする。

### 6.3 使用感

コインが接触する面にだけ、極めて薄い擦れと粗さの差を入れる。擦れは進行方向とコインが溜まる場所に関連させる。ランダムな汚れ、錆、全体を覆う傷テクスチャで質感を代用しない。

## 7. 下段：広く、狙いが読める主盤面

下段は広い一続きの金属面とする。上段より粗さを少し高くし、ボールとコインの輪郭が読み取りやすい状態にする。左右に色分けしたレーンや、報酬を示すマス目は設けない。

床は原則水平。外周の角は滑らかにつなぎ、メダルが引っ掛かる不要な突起をなくす。常に手前へ流れてしまう急な傾斜ではなく、押し台から伝わる力で前進する盤面にする。

左右端の最後1D程度には、手前へ開く浅い平面上の曲線を持たせる案とする。床の傾斜ではなく、側壁の向きを滑らかに変えて隅の滞留を減らす。力学で動かせる範囲に留め、隅のメダルを自動で中央へ移すことはしない。

### 側壁

床に接する下部は、継ぎ目の目立たない金属の立ち上がり。その上を薄い透明板につなぐ。金属部分はコインの山の根元を隠さない高さとし、ボール・倒れたタワーは透明板で受け止める。

側壁と床の間は閉じる。外側に細い落下溝、回収スリット、無得点の出口を作らない。透明板にも実際の境界としての厚みと連続性を持たせる。

背面も閉じ、上方には透明カバーを設ける。跳ねたコインが横・奥・上へ消えることを通常ルールとして扱わない。カバーの高さはレール上の立ったメダルを含めて確保する。初期目安は下段から8.5D以上で、タワーやボールの実際の運動範囲から確認する。

透明板の描写は、縁と少量の反射で存在を伝える。濃いスモーク、大きな映り込み、強い屈折で盤面を隠さない。

## 8. 手前の落下縁と回収口

下段の手前全幅を、途切れない一本の落下縁にする。左右端だけ受け取れない、中央に落ちたときだけ有効といった区別は設けない。

落下縁は薄い金属の面取りで表現し、そのすぐ下に暗い回収空間を置く。縁の上へ立ち上がる装飾は付けない。コインが支えを失う位置を常に見えるようにする。

回収空間は奥行きと高さを持つ。メダルも直径2.2Dのボールも通れる断面を確保し、細いコイン専用スリットに見せない。盤面から離れて落ち始めた状態と、回収が完了した状態を区別できるだけの距離を残す。

回収口の奥に、遮光された弱い暖色の反射を入れる。発光する太い枠や点滅するLED帯にはしない。獲得時の短い反応は、落ちた場所付近の小さな表示と音を中心にする。

手前の操作縁は回収口のさらに外側・低い位置に置く。ボタン、銘板、投入口の支点で、落下する瞬間を隠さない。盤面の手前から落ちた物は、筐体内の受け皿へ物理的につながって見えるようにする。

## 9. ボール・タワー・報酬供給の見せ方

### ボール

初期の球は落ち着いた琥珀色の半透明樹脂を候補にする。内部に小さな不透明部分を設け、回転がわかるようにする。全面を発光させたり、常に粒子をまとわせたりしない。

奥の背板に小さな専用供給口を置き、供給扉・短いレール・落下を見せる。左右の盤面端は閉じたままで、供給口が横の落下経路にならないようにする。球は通常メダルと区別できればよく、未決定のキャラクターを先に封入しない。

### タワー

タワーは特別な金色の台座に載せず、通常コインと同じメダルの積層として見せる。段ごとの隙間と小さな影、縁のハイライトを連ねる。頂上に王冠・旗・巨大な数字を自動追加しない。

搬入機構は奥寄りの機構帯から下段へアクセスする、閉じた搬送部として納める。可動台を貫通させず、必要な場合は盤面外の背面機構室から側壁内側の搬送路を使う。これは盤面外へ落とす穴ではなく、支持面と閉鎖扉を持つ供給機構とする。

盤面内側の扉は搬送面が受け渡し位置に達してから開き、扉が開いている間も床と囲いが途切れない納まりにする。搬送面を引き抜くときも、メダルが横へ流出する瞬間を作らない。詳細な機構形状は後日、立体で干渉確認する。

既存メダルがある場所へタワーを押し込まず、供給待ちにする。演出でメダルを消して空間を確保しない。動作終了後は盤面上の機構が目立たないよう退避する。

### JP払出し

背面機構帯に細い金属の払出し口をまとめ、実際のメダルが連続して出てくる形にする。コインの出どころを見せ、画面全体に巨大な文字をかぶせるより、盤面の変化を主役にする。供給口、球の出口、タワーの機構は役割の違いが形でわかるようにする。

## 10. 素材の作り分け

| 素材 | 必要な見え方 | デザイン上の粗さ目安 |
| --- | --- | --- |
| 上段の金属 | 細い面取りと方向のある反射。動くとハイライトが移動。 | 0.30〜0.40 |
| 下段の金属 | やや落ち着いた反射。メダルの輪郭を優先。 | 0.40〜0.50 |
| メダル | 面より縁が明るい。刻印に薄い影。 | 0.25〜0.35 |
| 外周の塗装 | 微細な表面粒、弱い艶。金属露出面とは異なる反射。 | 0.45〜0.60 |
| ブラス部品 | 鈍い金属光沢。黄土色の樹脂に見せない。 | 0.35〜0.45 |
| 透明板 | 低い粗さ、控えめな映り込み、板の縁。 | 0.05〜0.12 |

数値は見た目を合わせる開始値であり、特定エンジンでの保証値ではない。全素材に同じ反射設定を与えない。塗装は非金属の表面として、露出した金属は金属として扱い分ける。

ヘアラインは薄く、最終的なスマホ表示で縞やノイズにならない密度にする。細部を読めなくなるほどのシャープな模様を全面に貼らない。表面の傷は色の濃淡だけでなく、必要に応じて反射の違いで見せる。

### コインの形

表裏の浅い刻印、細い縁の段差、軽い面取りを持たせる。巨大な数字、星、王冠などを全面に彫るデザインにはしない。テーマ未決定の試作では、小さな幾何学的な刻印と控えめな円周模様を用いる。

同じ額面のコインは同じ材質と形を基本とし、向きとごく小さな摩耗の差で自然さを出す。各コインをランダムな色にしない。床との間、コイン同士の間に接触の影があり、縁の厚みで重なりを読めることを重視する。

## 11. 照明とカメラ

### 照明

- 主光は正面斜め上からの広く柔らかい中性色。上段・下段・コインを一度に読める明るさにする。
- 反対側から弱い補助光を入れ、下段の山やタワーの根元を真っ黒にしない。
- 奥の機構帯は少し暗く保ち、落ちてくるメダルを分離する。
- 琥珀色は操作灯と回収口のごく一部に限定。全体をオレンジ色へ染めない。
- 金属には幅のある反射を与える。点光源だけでギラギラした斑点を作らない。
- 影はメダルの接触と台の段差を支える。強いブルームで形状を溶かさない。

### カメラ

縦画面の中央に筐体を置き、正面から下を向く。初期構図は水平面に対して50〜55度程度の見下ろしを候補とし、極端な広角を避ける。レールの近い支点だけが巨大に見えない画角へ調整する。

盤面・投入経路で画面の約75〜82%を使い、情報と操作は残りの上下にまとめる。上段の奥の着地、下段のタワーの基部、手前の落下縁が同時に見えることを優先する。

カメラは左右中央を基本にし、レールでタワーの根元が隠れる場合はタワー配置を先に調整する。透明化してレールを消す解決に頼らない。常時のカメラ揺れ、無操作時の周回、過剰な被写界深度は加えない。

## 12. 文字・情報表示の扱い

盤面上に常設するラベルは最小限にする。残高、次のイベントまで、ボール収集状況は筐体外の簡潔な情報帯へまとめる。カードを何枚も浮かべたり、盤面へ巨大な進捗リングを重ねたりしない。

フォントは読みやすいサンセリフを基本にする。架空の英文ロゴ、意味のない製品番号、装飾だけの警告文字を追加しない。レール支点の小さな目盛りなど、機能を説明する刻印は許容する。

イベントの演出枠は後からテーマを差し替えられる場所に限定する。盤面素材や筐体の基本形にキャラクターを焼き込まない。

## 13. 横落ち廃止に伴う旧設計の変更点

| 旧設計の場所 | この追補で優先する内容 |
| --- | --- |
| 4.1 左右の落下溝 | 廃止。閉じた側壁と連続床を設ける。 |
| 4.1 盤面12D×16D | このデザイン基準は14D×18D。正確な寸法は立体確認で調整。 |
| 4.2 首振り±35度 | 奥への到達を保てる約±17度を開始案とする。 |
| 5 横落ち回収・無得点消去 | 通常の遊びから削除。メダルの正規出口は手前のみ。 |
| 7.2 球の側方回収・再供給 | 廃止。ボールも手前のみで回収。 |
| 9.2 タワーの搬入 | 閉じた床・囲いを維持する機構にする。横の開口から流出させない。 |
| 12 CollectionSystem・Economy | 横落ち処理を前提にしない。旧totalSideLostを通常集計として採用しない。 |
| 15 P1の横落ち | 横落ちの実装ではなく、左右・背面から出ないことの確認へ変更。 |

「横に落ちたが自動返還される」も採用しない。横へ落ちる構造そのものを作らない。画面の外へ出た物を消して帳尻を合わせる仕様にも変えない。

横落ちによる減少がなくなるため、旧版の確率・報酬値・物体数の見積もりは再調整の対象になる。長期的な残高増加や盤面混雑を後日確認する。対策として隠れた損失、見えない回収穴、獲得の間引きを導入しない。今回は新しい抽選確率や経済ルールを決定せず、盤面の指定を確定する。

## 14. Solが後日制作するときの判断順

1. 本書の優先事項と旧設計の差分を読む。
2. カメラ内で、手前の投入口、最奥の着地、上段の前縁、下段の手前回収が一目でわかる構図を作る。
3. レールの左右端、押し台の前後端、タワー搬入中でも、干渉や横の開口がないことを立体で確認する。
4. 上段・下段・外装の厚み、縁、継ぎ目を整える。
5. 接触の影と素材ごとの反射を合わせる。
6. 最後に薄い擦れ、小さな刻印、局所的な表示灯を加える。

最初から装飾で埋めない。完成度を上げる順は、構図、比率、形状、照明、材質、微細なディテールとする。プリミティブを並べた段階を完成版として扱わない。

### 後日のデザイン確認に必要な画角

- 通常プレイ視点：縦画面で投入経路と上下段と回収口が同時に見える。
- 真上：閉じた左右壁、首振りの範囲、下段の広さがわかる。
- 側面断面：手前高・奥低のレール、奥への落下、上下段の段差、手前回収がわかる。
- 素材の寄り：コインの縁、棚のヘアライン、外周の塗装が異なる材質に見える。

今回はこれらの画像・モデルも制作しない。後日の制作物を確認する際の要件として残す。

## 15. 完成時のデザイン合格条件

| 観点 | 確認する状態 |
| --- | --- |
| 投入方向 | 説明なしでも、メダルが手前から最奥へ移動してから落ちるとわかる。 |
| 首振り | 支点からレール全体が向きを変え、左右端でも奥の着地帯に収まる。 |
| 上下段 | 高さ、面の反射、前縁の影で2段構造が読める。 |
| 横落ちなし | 左右と背面が連続して閉じ、供給時にも損失経路が開かない。 |
| 手前の出口 | 盤面の全幅が回収口へつながり、コインもボールも通れる。 |
| タワー | 独立コインの積層に見え、レールに当たらず、根元が観察できる。 |
| 素材 | 棚・塗装・メダル・透明板の違いが、色だけでなく反射でわかる。 |
| 接触 | コインが浮いて見えず、重なりと支えが自然に読める。 |
| 機構 | レール、動く棚、搬送部がどこに支えられているかわかる。 |
| 画面密度 | 情報や装飾より盤面が大きく、スマホで落ちそうな縁が読める。 |
| 統一感 | 色・面取り・部品の継ぎ目・照明が同じ機械のものとして揃う。 |
| テーマの余地 | 未決定のキャラクターや世界観が盤面の基本構造を固定していない。 |

不合格の例は、全面鏡面の金属、紫と青のネオン、発光する格子、巨大な英語ロゴ、理由のない六角形、太い発光枠、空中に浮く機構、過剰な角丸、全面に同じ傷模様、コインの落下を隠すUI。これらを高級感の代替として足さない。

## 16. 引き継ぎ要旨

Solへの後日の制作依頼では、まず本書を読み、次にGAME_DESIGN.mdを読むこと。盤面の構造・見た目・横落ちの扱いが衝突した場合は本書を優先する。

採用案は、深緑の半艶塗装、銀のサテン金属、少量のブラス、弱い琥珀色の光。手前支点の細いレールで縦に立ったメダルを奥へ送り、奥の可動上段へ落とす。上段前縁から広い固定下段へ、下段から手前の全幅回収口へ進む。左右・背面・上方は囲い、横落ちを作らない。装飾ではなく、比率、板厚、接触の影、素材の反射で品質を出す。

イベント内容と世界観はユーザーとの相談で決める。本書の作成は、ゲームを実装する依頼ではない。
