# イベント・JP再点検（2026-10-17）

## 判断と改善

旧版は外れでも必ず二つの絵柄をそろえ、通常結果まで8.4秒＋結果4.8秒を使っていた。これでは予告の意味が薄く、タワーやJPで多数のメダルを回収すると通常イベントの待ち行列も長くなる。外れ4秒、5/10枚5.8秒、ボール・タワー・JP関連11.4秒に分けた。「停止・次へ」は演出だけを短縮し再抽選しない。

ミニボール3個を集めた航路チャレンジが通常抽選と同じ外れ20%だった点も修正。JP準備アイテムに加えて、外れのない航路別抽選を行う。JPの航路球は、名前と次の投球シードを変えるだけだった旧仕様から、当たり枠・球数・補強のいずれかを獲得する段階へ変更した。

これは「必ず面白い」と断言する評価ではない。待ち時間、積み上げの無駄、意味のない抽選、現在の有利さが読み取れない表示を減らす改修である。長時間の実プレイでの飽き、難易度の好み、端末ごとの操作感は引き続き評価が必要。

通常抽選は従来のユーザー指定を維持する。手前でメダル30枚を獲得するたびに1回。

ミニボール1個は10枚の盤面払出し＋配達スタンプ。同じ航路3スタンプで上記のチャレンジと準備アイテムを獲得する。灯台は次回JP＋1マス（2個まで）、海路は改装上限＋1球、工房は突風を防ぐ補強（各1個まで）。一度選んだ配達先・獲得済み報酬はリロードで変わらない。

通常1回あたり、すぐ数量が確定する盤面への追加は12.3枚相当（5枚・10枚・120枚タワー・JP直撃の期待枚数の合計）。これに大きいボール、JP挑戦の将来価値が加わる。手持ちへの直接付与ではなく、再び前へ落とす必要がある。横落ちなし・無料補充ありの長く遊べる設計なので、実機の収益設定や回収率を再現した数値ではない。

## JPの流れと判断

1. 航路球：灯台ならJP＋1、海路なら改装上限＋1球、工房なら補強1個（既に所持なら10枚）。10穴に各3穴＋いずれか1航路の追加穴を配置。追加航路と配置を毎回抽選するため、開始前の平均は各1/3。当該画面では3穴または4穴になる。
2. 改装球：JP＋1が30%、＋2が10%、突風−1が20%、補強10%、10枚20%、出航10%。最大3球＋航海図1球＋海路1球。JPは1〜5マス、補強は減少を1回防ぐ。
3. 各球の結果後、「この状態で出航」か「もう1球」。画面に現在のJP枠、補強、残り球数、突風20%と8秒の期限を示す。未操作は現在の状態で出航。出航穴・上限到達でも最終へ進む。
4. 最終球：JPがs穴、30枚が2穴、10枚が8−s穴。出航時に配置を確定し、投球後に書き換えない。球が物理的に入った穴で結果を決める。
5. JP以外の最終結果が3回続くと、次のJP開始時に＋1枠。準備アイテムと救済は1回だけ消費し、その後集めたものは次回へ持ち越す。

JP枠が少ない間は増やす余地が大きい。5枠では灯りを増やせず、補強なしの突風は損になるので、そこで出航する判断が意味を持つ。補強ありなら1回の突風を受けても枠を維持できる。どの方針も勝利は保証しない。

### 最終JP率の理論値

準備・救済なし、改装は5枠になるまで継続し、5枠なら出航する方針を状態遷移で計算した値。穴ラベルを投球とは独立に毎回シャッフルする前提。特定の配置で球が各穴へ均等に入るとの主張ではない。

最初の改装結果で毎回出航する場合の平均は17.667%。未強化の最終盤だけを見た10%と、航路・改装を含む1挑戦全体の率を区別する。再現用の計算は `scripts/event-odds-audit.ts`（`node --import tsx scripts/event-odds-audit.ts`）。

## 画面とルーレット

- ヘッダー・投入操作・セーフエリアを除いたプレイ領域を上40%・下60%に固定。イベントは盤面を覆わず、サイズ変更ボタンも設けない。
- ルーレットの床と穴は物理判定と同じメッシュ。ボールの位置・回転も物理結果を表示する。装飾灯だけが回り、当たり穴を球に追従させる演出はしない。
- 深い紺の筐体、真鍮の外周、薄いガラス、穴の内壁、外周の報酬プレート、球の金属帯と接地影を使用。カメラは縦横比から調整し全穴を表示する。
- ゲートの開放時刻、現在のJP枠、入賞箇所の点灯、確定した報酬を明示。紙芝居と抽選の表示切替中も球は進む。
- 描画資源は抽選切替時に解放。共有環境マップを利用し、抽選用にもう一つWebGLレンダラーを作らない。
- 既存の進行中JPは保存された配置と状態で完了。旧ラベルの航路に新たな恩恵を後付けしない。

## 検証項目

確率の境界・合計、航路ラベルの配置分布、各恩恵の一回だけの適用、保存復元、旧抽選の互換性、100投で全10穴への到達と同一結果の復元を自動検証する。画面では縦長・低い横長・デスクトップを確認し、6:4、盤面との非重複、選択ボタン、入賞表示、イベント中の投入継続を点検する。
