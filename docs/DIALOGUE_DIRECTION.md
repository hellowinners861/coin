# セリフの最新方針（2026-10-20）

ユーザー要望：全キャラクターの味気ないセリフを改善。「空、綺麗だね。」のように名詞と読点で区切るだけの単調な台詞をなくす。

本書と実装中の `src/events/scripts.ts` を最新版とする。古い絵コンテ・企画書の台詞は過去案であり、再実装時に復活させない。

## 人物の書き分け

- ナギ：操船に自信がある行動派の配達員。地名には弱い。思いつきを口にしてミナに訂正されるが、荷物を大事にする仕事の芯がある。一人称は僕。明るさを毎回の絶叫にしない。
- ミナ：話が早いカモメの連絡係。食いしん坊で機転が利く。ツッコミは相手を傷つけず、すぐ次の行動へ進む。「〜わよ」「〜でしょ」を使えるが全行同じ語尾にしない。
- ガロ：頼れる整備職人。長々と説明しないが、文を名詞だけに切り刻まない。「直した」「任せとけ」など仕事を引き受ける言葉にする。時々、誰よりも優しい一言を言う。

## 書き方

1. 一言に「何をしたいか」「相手への反応」「その人らしい具体物」のどれかを入れる。
2. 会話は前の発言を受け、行動や小さなオチへ進める。独立した雰囲気文を並べない。
3. 風景を語るなら人物の目的につなげる。「雨、止まないね」ではなく、花束を守った結果ナギだけ濡れた、といった状況にする。
4. 句読点は自然な文章のために使う。「ゲート、開いた」「奥へ、送るぞ」等の機械的な区切りをしない。
5. 説明UIは正確な数値を簡潔に表示。セリフに性格を付けても、報酬・残り球・上限を曖昧にしない。
6. 盤面の状態を見ていない待機会話で「あと1個」「崩れそう」等を断定しない。当選確定前に結果を予告しない。
7. 早く消える外れ・5枚・10枚の結果は短くする。日誌は3.6秒の1カットに収まる文量を目安にする。台詞のために抽選を延長しない。
8. 台詞に応じてsurprise / joy / sad / normalを選ぶ。紙芝居回転と固定表示枠を保つ。

## 改善例

- 待機：ナギ「灯台まで近道を見つけた！」→ミナ「その線をたどると海に飛び込むけど？」→ナギ「泳げば近道にはなるよね？」→ミナ「手紙を濡らしたら配達にならないでしょ。」
- タワー：ガロ「積んでおいたぞ。崩しがいがあるだろ？」
- 修理した船の名前：ガロ「直したのは船だ。思い出まで替えることはない。」
