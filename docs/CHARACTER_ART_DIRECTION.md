## 色彩と質感

- 比較用背景：`#FFFFFF`。文字と列番号は濃いグレー。薄い影を使う場合も中立グレー。
- 衣装：深い緑。濃淡はセルの面で整理する。
- シャツ・羽・顔の白部分：白を基準とし、影は中立または僅かに冷たいグレー。
- 毛・革：自然な茶色は残す。画面全体へ黄・オレンジを重ねない。
- 金具：小さな真鍮色。肌や背景まで金色に染めない。
- 線：意図のあるアニメの輪郭。無数の毛や布目を描き込むより、輪郭・表情・明暗の形を優先。

ゲーム筐体の深緑・銀・真鍮は維持する。白背景という指定は比較シートの背景に適用し、ゲーム本体の背景を白へ変更する指定とは扱わない。

## 制作済みのものと、次に必要なもの

採用前の比較では、各キャラクターを一枚のシートにC1/C2/C3で横並びにした計3シート・9案を生成した。最新の制作対象は、採用済みC3から派生する通常3ポーズ・ちび2ポーズ、計15図。完成ムービー、透過パーツ、口形・まばたきの連続差分、3Dメッシュは含まない。最終の生成プロンプトは[プロンプト記録](CHARACTER_GENERATION_PROMPTS.md)に残す。生成手段は組み込みの画像生成機能。

C3採用後に必要な素材：

1. 正面・左右斜め・横・背面のデザイン確認。
2. 通常、期待、驚き、喜び、残念、台詞の口形とまばたき。
3. 上着・腕／翼・鞄・尾など、採用するアニメーション方式に対応したパーツ。
4. 上部待機の小サイズと、中央の大きなカットインでの読みやすさ確認。
5. ナギ・ミナ・ガロを同じ線幅・頭身の体系・セル影・光源へそろえた最終三人組シート。

画像生成で立体的に描かれた案があっても、それだけで3Dモデルを得たとは扱わない。比較シートをそのまま切り抜いて完成リグと見なさず、採用後に本番用素材を整える。

## 選定の観点

- 上部で小さく表示しても誰か分かるか。
- カットイン時に一言と一動作で性格が伝わるか。
- 9案の中で、三人の線と塗りを統一しやすい組合せか。
- まばたき・口・腕や翼・尾の動きを制作しやすいか。
- 白い部位が黄ばんでいないか、影で顔の表情が読めなくならないか。
