# 港の郵便局：画像とイベントの実装

2026-10-16

## 収録内容

- 背景9枚：郵便局の外、仕分け室、積み込み桟橋、ガロの工房、抽選ドック、出港、干潮の船着場、雨の食堂、夕暮れの岬の家。
- ナギ・ミナ・ガロ各4表情の透過アトラス。通常・驚き・喜び・困り顔。採用済みの漫画風の顔・衣装を参照して画像生成。設計にある将来の全ポーズ39点を揃えたものではない。
- 待機会話6本、通常イベント7結果、JP抽選3結果、JP後の配達日誌3話。日誌はJPごとに1話開放し、設定から再読できる。
- 背景・人物・吹き出しを分離。CSSの縦軸360度回転中、90度の位置で表情を差し替える。裏向きの区間は画像を反転補正して、顔を鏡写しにしない。動きを減らす設定では即時切替。

画像は `public/events/*.webp`。生成プロンプト・参照・元画像名は `public/events/generation.json`。配信向けに縮小・WebP化し、絵そのものへの加筆はしていない。背景は1200px幅、透過アトラスは1024px四方。元の生成PNGは変更していない。

## 画面と進行

待機会話は上部モニター。イベントは中央にカットインし、「上へ」ボタンまたは上スワイプで縮小する。「中央へ」または下スワイプで戻す。同じDOMと再生時計を維持し、画面移動で再抽選しない。

JP導入後は会話を上へ送り、3D抽選機を中央へ出す。会話を中央に戻すと抽選機は上へ移る。両方を上にした場合は左右に並び、「盤面を再開」を押すまで盤面を止める。中央のイベント・日誌・抽選中は盤面と自動投入を止める。上の通常イベントを見ながらの盤面プレイは可能。全体停止・設定・非表示タブでは物語と抽選機も止める。

スワイプは縦48px以上、縦移動が横移動の1.35倍以上で判定。ウィンドウからの操作は盤面の投入口ドラッグに伝播させない。ボタンでも同じ操作ができる。

## JPは物理抽選

Rapierの独立したワールドに球、傾斜した抽選皿、外周壁、実際の10個の開口を置く。最初の3.2秒は全穴のゲートが閉じ、球が皿を回る。その後すべてのゲートを一斉に開く。球が実際に穴の下へ落ちてから結果を確定する。球への当たり穴誘導、当選結果に合わせた穴の差し替え、一定時間経過による架空の入賞は行わない。

穴の配当は投球前に、10枚7個・30枚2個・JP1個を一様にシャッフルする。配当配置の抽選と投球シードを分け、配置は投球中に変わらない。物理的な穴ごとの入りやすさが均等でなくても、各穴の配当が同じ70/20/10の周辺確率なので、報酬の確率は指定通りになる。有限回の実測結果が毎回この割合になる保証ではない。

球が24秒以内に入らなければ「球を入れ直す」を表示。同じ配当配置で新しい投球だけを行い、未確定の報酬は増やさない。未確定の物理抽選はスキップで結果を作らず、導入だけを飛ばす。

盤面と抽選機は同じWebGLRendererを使い、抽選ウィンドウの矩形だけをscissor/viewportで上描きする。追加のWebGLコンテキストは作らない。

## 報酬と保存

通常イベント：なし20%、5枚20%、10枚35%、ボール18%、タワー4%、JP抽選2%、JP直撃1%。JP抽選：10枚70%、30枚20%、JP300枚10%。メダルは既存の左射出口から盤面へ払い出し、手前へ落とすまで手持ちに加算しない。ミニボールの10枚払出しは小さな通知で案内し、JP進行とは分ける。

結果適用はチケットID・適用済みフラグで一度だけ。抽選途中のワールド・球ハンドル・ゲート・固定刻みの余り時間、チケット、払出し権、日誌の開放/既読と再生時間、上下の配置を、盤面と同じIndexedDBレコードへ保存する。盤面が停止中でも4秒ごとに保存する。日誌の再読は報酬を生まない。

以前の保存データは互換を維持。すでにデジタル抽選で結果が決まっていた旧JPチケットはその結果を維持して会話演出で消化し、次のJPから物理抽選にする。旧JPで取得済みの回数に対して日誌を遡って自動開放はしない。

## 検証

`npm test` と `npm run build`。イベントテストでは100シードの物理落下と途中スナップショット復元の一致、全10穴への到達、未確定スキップ・保存後の二重払出し防止、配当配置と日誌待機を確認する。統計テストは配当シャッフルの偏り検出であり、ゲーム全体の払い戻し率や実機の性能保証ではない。

### 小さい画面での配置調整

中央ウィンドウを上部モニターより下の空き領域に配置し、高さが足りない場合は縦横比を保って幅を縮める。会話を中央へ戻した場合にも同じ調整を行う。10穴の配当表示はトーンマッピングの影響を受けない文字にし、サイズを拡大した。盤面停止中は操作欄にも停止理由を表示する。

### 2026-10-16 盤面に重ねない配置へ変更

待機会話・通常イベント・日誌・JP抽選を、盤面とは別のイベント専用エリアへ移動。縦画面では上段のモニターと下段の盤面、低い横画面では左のモニターと右の盤面に分ける。拡大・縮小も専用エリアの中で行い、イベントの画面移動で盤面を覆わない。「中央へ／上へ」のボタン表示は「大きく／小さく」に変更。以前の中央重畳表示の記述より、この追記を優先する。

盤面カメラは盤面エリアの寸法に合わせて再計算し、全体が見えるよう縮尺を調整する。1つのWebGLRendererで、盤面と抽選機を互いに独立した矩形へ描画し、各矩形の外へは描かない。物理ワールドと抽選の進行・保存処理は継続する。

### 2026-10-16 段階式イベントと床下タワー

通常抽選を、3リール停止（2.4秒・4.2秒・8.4秒）、リーチ、配達結果の順に拡張した。結果は従来と同じ通常テーブルで一度だけ抽選し、停止ボタンは演出時計だけを進める。ナギの灯台便・ミナの海路便・ガロの工房便で背景と台詞、3つの進行表示を変える。ハズレのリーチも発生するが、ハズレで当たりの3絵柄を揃えない。

ミニボール1個ごとに、従来通り10枚の盤面払出し権をその場で発行し、専用の小包開封イベントを保留列に追加する。イベントでは灯台・海路・工房から配達先を選び、同じ航路にスタンプを3個集めるとその航路の追加チャレンジを1回発行する。追加チャレンジも通常と同じ7結果・確率で抽選し、リールは3秒・6.2秒・10.8秒で停止する。スタンプの選択は意味のある収集先の選択で、通常の停止ボタンによる抽選確率の変更とは分けている。未操作5秒、または演出を閉じた場合は、現在のスタンプが最も多い航路（同数なら灯台→海路→工房）を選ぶ。回収した1個に対してスタンプも10枚も一度だけ。別の抽選や日誌の途中では保留し、再読込で消さない。

JPを2球の物理抽選に拡張。第1球は10穴の1/2/3表示で灯台・海路・工房を選ぶ。穴数は4/3/3で、報酬は出さない。第1球の入賞後2.4秒のゲート演出を挟み、第2球で10枚・30枚・JP300枚を決める。最終配当は7穴・2穴・1穴を独立にシャッフルするため70%・20%・10%を維持し、航路の差で最終配当確率は変わらない。第1球で決まった航路は最終球の投球シードにも反映する。入賞前に報酬を確定する演出や、リーチで当選を保証する表示はしない。第1球と第2球のワールドをそれぞれ保存し、途中の橋渡し演出も続きから再開する。以前の保存にある1球式JPはそのまま完了させる。

タワーは空き領域の判定を廃止。前後に滑る2枚の床扉が盤面のメダルを支えた状態でリフトを下げ、下で120枚の動的剛体を組み立てる。扉の開放に合わせてリフトを上昇させ、扉との摩擦とタワー・ガイド枠との衝突で既存メダルを押しのける。既存メダルの削除・移動・直接加算をしない。タワーが立っている間は次の権利を保留し、崩壊後に次を組み立てる。盤面900枚の容量制限による権利保留は維持する。

新機構の工程は床扉閉鎖0.65秒→リフト下降0.75秒→組立待ち0.4秒→扉開放0.7秒→せり上げ3.5秒→ガイド引き下げ2秒。床扉の位置、工程、120枚分の予約、開始位置を保存する。旧スナップショットには床扉を追加し、既に旧方式で搬入中のタワーは旧方式で一度完了させてから新機構へ移行する。

## 横長モニター・イベント中の継続動作（最新仕様）

上部のモニターは横幅いっぱいに表示し、高さに合わせて幅を縮めない。横画面でも上部の横長モニターと下部の盤面に分け、盤面へ重ねない。拡大・縮小はモニター領域の高さを変える。物理抽選中はモニター全体で抽選を表示し、「物語へ」「抽選へ」で表示内容を切り替える。物語を見ていても抽選球は動き続ける。

通常イベント・ミニボール・日誌・JPの導入、航路抽選、最終抽選、結果表示を通して、盤面の物理計算・プッシャー・メダル払出し・手動投入・ONになっている自動投入を継続する。「盤面を再開」の操作は不要。設定・ヘルプ・補充確認・タブ非表示など、全体の一時停止は従来通り。イベント中に成立した次の抽選は保留列へ入れる。この追記を以前のイベント中停止・左右分割の記述より優先する。

検証：ビルド、既存の物理・抽選テスト、Chromiumで通常イベントとJP抽選中のシミュレーション時刻・プッシャー時刻・自動投入枚数の増加、設定中の停止、物語／抽選の切替後の抽選継続を確認。390×844、390×700、844×390、1280×900でモニターが領域幅の93%以上を使用し、盤面との重なりがないことを確認。生成済み背景・キャラクターと実際のWebGL抽選表示も確認。
