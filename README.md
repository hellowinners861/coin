# coin

左右に向きを振れる投入口からメダルを落とす、3Dメダルプッシャーゲームの企画リポジトリです。

[ゲーム設計書](docs/GAME_DESIGN.md)

設計には、ランダムボール、獲得枚数に応じたイベント、メダル報酬、ジャックポット、個別のメダル剛体からなるコインタワー、スマートフォンでの物理検証方針をまとめています。実機の公式資料・攻略記事への参照も設計書内に記載しています。

ブラウザで動く3Dゲームを実装しています。イベントのテーマ・キャラクター・具体的な内容は、今後の相談で決定します。


**盤面の最新仕様：** [盤面デザイン追補・Sol向け制作指示書](docs/BOARD_DESIGN_ADDENDUM.md)

手前から最奥へメダルを送る首振りレール、上下段の造形・素材・照明、横落ちのない手前全幅回収を定めています。盤面に関する旧設計との相違は、この追補を優先してください。

## 起動

Node.js 24を使用します。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザで開いてください。PCでは左右キーで首振り、スペースで投入。スマートフォンでは盤面の左右ドラッグまたはスライダーで狙い、投入ボタンを押します。長押しで連続投入できます。

## 検証・配信

```sh
npm test
npm run build
npm run preview
```

`dist/`を静的ホスティングへ配置できます。相対パスでビルドするため、サブディレクトリへの配信にも対応します。GitHub Actionsはテストとビルドを行い、`coin-static-site`アーティファクトを作成します。ホスティング設定の変更や公開は行いません。

進行はブラウザ内のIndexedDBへ保存されます。同じ端末・ブラウザで再開してください。サウンドは設定で有効にできます。重い場合は描画品質を「軽量」にしてください。

## 実装の状態

ランダムボール、通常イベント、JPC、JP300枚の分割払出し、120個の独立剛体によるタワー、保存・再開を含みます。初期配置・時間刻み・搬入機構の検証に伴う調整と、検証できた範囲は[実装記録](docs/IMPLEMENTATION.md)に記載しています。

スマートフォンでのFPSやブラウザ上の見た目・タッチ操作は、実機での確認が必要です。イベントはテーマ未決定の中立的な抽選表示です。
