# coin

左右に向きを振れる投入口からメダルを落とす、3Dメダルプッシャーゲームの企画リポジトリです。

[ゲーム設計書](docs/GAME_DESIGN.md)

設計には、ランダムボール、獲得枚数に応じたイベント、メダル報酬、ジャックポット、個別のメダル剛体からなるコインタワー、スマートフォンでの物理検証方針をまとめています。実機の公式資料・攻略記事への参照も設計書内に記載しています。

ブラウザで動く3Dゲームを実装しています。イベントのテーマ・キャラクター・具体的な内容は、今後の相談で決定します。


**盤面の最新仕様：** [盤面デザイン追補・Sol向け制作指示書](docs/BOARD_DESIGN_ADDENDUM.md)

手前から最奥へメダルを送る首振りレール、上下段の造形・素材・照明、横落ちのない手前全幅回収を定めています。盤面に関する旧設計との相違は、この追補を優先してください。

## 起動

Node.js 24を使用します。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザで開いてください。PCでは左右キーで首振り、スペースで投入。スマートフォンでは盤面の左右ドラッグまたはスライダーで狙い、投入ボタンを押します。長押しで連続投入できます。

## 検証・配信

```sh
npm test
npm run build
npm run preview
```

`dist/`を静的ホスティングへ配置できます。相対パスでビルドするため、サブディレクトリへの配信にも対応します。GitHub Actionsはテストとビルドを行い、`coin-static-site`アーティファクトを作成します。ホスティング設定の変更や公開は行いません。

進行はブラウザ内のIndexedDBへ保存されます。同じ端末・ブラウザで再開してください。開始画面の「BGM・効果音をつける」または設定の「サウンド」で音を有効にできます。設定の「BGM」だけオフにすると効果音のみになります。重い場合は描画品質を「軽量」にしてください。

## 実装の状態

ランダムボール、通常イベント、JPC、JP300枚の分割払出し、120個の独立剛体によるタワー、保存・再開を含みます。初期配置・時間刻み・搬入機構の検証に伴う調整と、検証できた範囲は[実装記録](docs/IMPLEMENTATION.md)に記載しています。

スマートフォンでのFPSやブラウザ上の見た目・タッチ操作は、実機での確認が必要です。イベントはテーマ未決定の中立的な抽選表示です。

## 盤面・メダル追加の更新

新しい盤面は460枚（従来から100枚増量）。押す力を伝える密な下地に、位置・向き・重なりのランダムな表面層を重ね、物理計算で落ち着かせてから開始します。メダルは金色の面・縁・刻印と金属の反射で表現します。保存済みの盤面はそのまま再開します。新配置を試す場合は「設定 → はじめから遊ぶ」を選んでください。

タワー搬入口の場所にも初期メダルを置き、四角い空白を作りません。タワーの搬入権は実際に周囲が空くまで保持します。そこにあるメダルを消したり、重なったままタワーを生成したりしません。

水色のミニボールは初期3個。直径は従来の2倍、メダル直径1.28枚分（32mm相当）。下段左の奥寄りから手前へ供給します。大きいボールより小さく、軽く、摩擦を抑えた別の剛体で、前へ落とすと10枚の払出しを予約します。JP用の3個進行には含めません。投入10枚ごとに1個追加し、盤面と追加待ちを合わせて最大6個です。

通常の5枚・10枚報酬、ミニボールの10枚、30枚・JP300枚は、すべて上段左横の射出口から奥側へ供給します。自然な前進で上段が最も手前へ来た時に保持し、1枚ずつ物理的に射出してから往復を再開します。容量不足時は残数を保持して、次の前進へ保留します。奥側へ載りやすい高さと向きで送り、落下後に位置を整列させません。手持ちへ加わるのは実際に手前へ落ちた時です。無料の継続用100枚補充は、確認後に手持ちへ追加します。

手持ちが0枚になると、100枚を無料で追加するか確認します。「落下を待つ」や閉じる操作では追加せず、盤面の動きを再開します。後から画面下の追加ボタンでも受け取れます。追加は獲得枚数・抽選ゲージには含めません。

## 投入モード

左下の「1プッシュ」で1枚／3枚を切り替えます。3枚は同時に重ねて出さず、0.24秒以上の間隔で順番にレールへ送り、実際に投入した枚数を手持ちから使います。残りが1〜2枚なら、その分だけ投入します。盤面のドラッグで投入口の向きを変えられます。

「自動投入」をONにすると、上段が一番手前へ出る頃に上段へ到着するよう、レール通過時間を見越して1往復に1回投入します。1枚／3枚の設定に従います。OFFで未投入の自動分を止め、手持ち0枚でも自動停止します。補充後や再読込後は、ONにし直してください。設定や非表示中は盤面とともに停止します。

上段の往復は従来の1.5倍速（1往復3秒→2秒）。レール通過約0.95秒を見込み、1枚は周期位相0.05秒、3枚は1.81秒から0.24秒間隔で投入します。3枚は周期をまたいで中央の1枚を次の最前進に合わせます。報酬射出口にミニボールがいても射出を止めず、射出されたメダルとの接触は物理計算に任せます。

上段の動き幅は中心から前後0.9枚分、前後合計でメダル直径1.8枚分（25mmメダル換算45mm）です。従来の1.2枚分から1.5倍に広げ、1往復2秒を維持します。既存セーブでは現在位置を保持し、約1秒かけて新しい幅へ移行します。

ミニボールの追加供給は高さ3.6Dから（従来の2.6Dよりメダル直径1枚分高い位置）。報酬メダルは射出口周辺のミニボールやメダルを待たずに射出し、接触は物理計算に任せます。近くのメダルによって間接的に射出が止まる判定も撤去しました。盤面の枚数上限に達した場合は、払出し残数を保持して空きを待ちます。

通常イベントは手前へ落ちたメダル30枚ごと。報酬なし20%、盤面5枚20%、盤面10枚35%、大きいボール1個18%、120枚タワー4%、JP抽選2%、JP直撃300枚1%。大きいボール3個またはJP抽選当選でJP抽選へ進み、盤面10枚70%、盤面30枚20%、JP300枚10%です。キャラクター演出の対応案は[イベント・確率の一覧](docs/EVENT_STORY_PROPOSAL.md)を参照してください。

### 段階式イベントと配達スタンプ

通常抽選は3リール・リーチ・配達チャレンジです。ミニボール回収でも小包開封イベントが発生し、10枚払出しに加えて配達先を選べます。同じ航路のスタンプ3個で追加チャレンジとJP準備アイテムを獲得。通常イベントの確率は上記のままです。タワーは右奥のメダルを空ける必要がなく、床扉とリフトで押しのけながら120枚がせり上がります。既存のメダルは物理計算で動きます。

### 灯台JPと話者に追従する吹き出し

新しいJPは「航路決定 → 改装チャレンジ → 最終抽選」の3段階。改装の物理球でJPマスが増減（1〜5個）し、補強で減少を1回防ぎます。「出航／もう1球」を選べ、未操作8秒では現在の条件で出航。通常3球、航海図ありなら4球までです。配達完了で次回のJP＋1・追加球・補強を準備でき、最終抽選に3回失敗すると次のJPを＋1で開始します。未強化の最終穴構成は従来通り10枚7穴・30枚2穴・JP1穴で、強化により10枚穴がJPへ置き換わります。抽選中も盤面は止まりません。

吹き出しは話者の頭上へ移動し、しっぽをキャラへ向けます。リールなどの操作部分はキャラを覆わない別行に配置します。[実機の参考・ルール・保存互換性](docs/JP_REFIT.md)を参照してください。


## 横長モニター・イベント中の継続動作（最新仕様）

上部のモニターは横幅いっぱいに表示し、高さに合わせて幅を縮めない。横画面でも上部の横長モニターと下部の盤面に分け、盤面へ重ねない。拡大・縮小はモニター領域の高さを変える。物理抽選中はモニター全体で抽選を表示し、「物語へ」「抽選へ」で表示内容を切り替える。物語を見ていても抽選球は動き続ける。

通常イベント・ミニボール・日誌・JPの導入、航路抽選、最終抽選、結果表示を通して、盤面の物理計算・プッシャー・メダル払出し・手動投入・ONになっている自動投入を継続する。「盤面を再開」の操作は不要。設定・ヘルプ・補充確認・タブ非表示など、全体の一時停止は従来通り。イベント中に成立した次の抽選は保留列へ入れる。この追記を以前のイベント中停止・左右分割の記述より優先する。
